# Mini Quiz App

A command-line quiz application built in Python for the ACE (Association of
Computer Enthusiasts) society submission.

## Status

🚧 Under active development — built incrementally, commit by commit.

## Planned Features

- 10+ quiz questions, stored separately from the main game logic
- One question shown at a time, with the user's answer accepted and checked
- Score tracking, with the correct answer shown when the user is wrong
- Final score and a performance message at the end
- **Bonus:** randomized question order
- **Bonus:** category selection
- **Bonus:** a timer per question
- **Bonus:** a persistent high-score system

## How to Run

\`\`\`bash
python main.py
